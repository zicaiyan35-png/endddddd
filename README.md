#  舊市尋味：臺中第二市場與在地文史探索

歡迎來到 **endddd** 專案！本專案是以臺中第二市場為核心的文史導覽數位實踐平台。我們透過田野調查、歷史建築考究與在地飲食文化梳理，帶領大家重新走入百年市場的常民記憶。

## 專案緣起與目標
* **探索歷史紋理**：深入研究臺中第二市場的發展脈絡，聚焦於具代表性的中央「六角樓」及周邊歷史建築。
* **結合在地飲食**：挖掘市場內的道地傳統小吃與傳統風味，傳遞豐富的庶民生活美學。
* **數位文史展現**：運用所學的網頁前端技術（如 HTML5 與 CSS 結構），打造具備人文關懷與響應式設計的城市漫步指南。

##  專案特色
* **復古美學視覺**：採用融合手感與懷舊風格的視覺排版（如撕紙拼貼等美學概念），展現舊城區獨有的歷史厚度。
* **互動導覽體驗**：結合在地路線規劃與街區漫步（City Walk）概念，讓使用者能按圖索驥，體驗兼具科技與人文溫度的在地文化。

##  技術堆疊 (Tech Stack)
* HTML5 / CSS3
* Responsive Web Design (RWD)
